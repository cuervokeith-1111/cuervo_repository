Comic Book Management System

A desktop-style management system for a comic shop, covering sales, inventory, borrowing, and user accounts.

  • Python
  • SQL
  • Dashboard

A full management system built to track a comic shop's daily operations. The dashboard surfaces key numbers at a glance — total sales, comics in stock, items currently borrowed, and low-stock alerts — alongside charts for recent sales and top-selling titles.

Beyond the dashboard, the system handles comic inventory, point-of-sale transactions, borrow and return records, sales history, reports, and user accounts. Built with Python and SQL to keep the data organised and every record queryable.

Sunrise Enrollment System

A school website with an open-enrollment flow, strand information, and a notice banner for applicants.

  • Vue.js
  • Tailwind CSS
  • PHP

A website for Sunrise Senior High School built around its enrollment period. A notice banner announces that SY 2026-2027 enrollment is open for Grade 11 and Grade 12, and reminds early applicants they get priority on strand slots.

Built with Vue.js for reactive components, Tailwind CSS for the styling, and PHP to handle enrollment submissions on the server. The site covers the school's four academic and TVL strands, the application procedure, announcements, and requirements, with clear calls to action for starting enrollment or comparing strands.
